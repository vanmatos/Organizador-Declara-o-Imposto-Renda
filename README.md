# 📊 Lex App Renda — Excel

## Sobre o projeto

Aplicação desenvolvida em Excel para auxiliar na organização de informações e documentos relacionados à declaração de Imposto de Renda Pessoa Física (IRPF).

A ferramenta permite registrar rendimentos, informes bancários e deduções legais ao longo do ano, facilitando a preparação das informações para a declaração ou o encaminhamento a um contador.

## 🔎 Funcionalidades

* Cadastro de informações do titular.
* Registro de informes de rendimentos bancários.
* Registro de rendimentos e receitas.
* Registro de deduções legais.
* Seleção de categorias por listas suspensas.
* Controle de comprovantes.
* Cálculo automático dos valores informados.
* Navegação entre as etapas da aplicação.

## 🛠️ Recursos de Excel utilizados

* Fórmulas e funções de soma.
* Validação de Dados.
* Listas suspensas.
* Tabelas estruturadas.
* Hyperlinks para navegação entre abas.
* Referências entre planilhas.
* Formatação personalizada de valores.
* Formatação de interface.

## 🗂️ Estrutura

**TITULAR:** informações pessoais do titular.

**INFORMES:** registro dos informes de rendimentos bancários.

**NOTAS:** registro de rendimentos e receitas.

**DEDUÇÕES:** registro de despesas e pagamentos que podem ser utilizados como deduções legais.

**TABELAS:** base de apoio utilizada pelas listas e validações.

## 📚 Aprendizado

Projeto desenvolvido para consolidar conhecimentos de Excel e servir como base para estudos posteriores em análise de dados, Power Query e Power BI.

**Obs.:** Projeto educacional. A ferramenta não substitui os sistemas oficiais da Receita Federal ou orientação profissional de um contador. Os dados utilizados são fictícios.
